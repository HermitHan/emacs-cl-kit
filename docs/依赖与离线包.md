# 包从哪里来

源码安装器首次运行时会联网取得固定版本的上游依赖。公开离线安装器内含第三方包源码，适合在有网的机器上下载，再带到断网机器使用。两种方式都由目标 Emacs 生成 autoload。装好后，日常编辑、编译、求值都可离线进行。[一行安装](../README.zh-CN.md#一行安装) · [离线安装器与校验文件](https://github.com/HermitHan/emacs-cl-kit/releases/latest) · [第三方来源与分发范围](third-party-distribution.md)

安装器按以下顺序选择依赖来源：

1. `EMACS_PORTABLE_PACKAGE_BUNDLE` 指定的本地快照。
2. 安装包内的快照，优先使用公开版的 `deps/public-offline-packages.tar.gz`，其次使用个人迁移版的 `deps/offline-packages.tar.gz`。
3. `EMACS_PORTABLE_BUNDLE_URL` 指定的 HTTPS 地址，需要直接指向其中一种内层快照。
4. 在线安装，按[清单](../deps/online-packages.json)下载固定归档，逐包校验 SHA-256 并仅安装清单列出的文件。

前面三种方式都检查快照的固定 SHA-256 及逐文件清单。指定的快照如果不匹配，安装器会报错退出。[公开离线包校验值](../deps/public-offline-packages.sha256) · [个人迁移包校验值](../deps/offline-packages.sha256)

在线来源共 214 份归档，211 份取自固定 Git 提交的 ELPA 历史镜像（`raw.githubusercontent.com`），2 份取自 GNU ELPA（`elpa.gnu.org`），gptel 优先取自 NonGNU ELPA（`elpa.nongnu.org`）。遇到暂时的连接故障，安装器会尝试内容哈希相同的备用来源，包括 jsDelivr 和上海交大镜像。完整的 214 个归档共约 26 MiB。

私用快照含 214 个第三方源码包：212 个[Mac 参考包](../deps/reference-packages.tsv)，另加用于 Emacs 29 的
compat 30.1.0.1、which-key 20240620.2145；Emacs 30 使用自己的同名内置库。
快照只选取参考列表内的第三方源码及其随包资源。排除字节码、原生编译缓存、
生成的 autoload、隐藏文件、用户历史、授权、macOS 应用和 LispWorks 映像。
目标 Emacs 重新生成 autoload 并以源码运行。SLIME 包含匹配的 Swank 源码，会为所选 Lisp 生成本机缓存。
已有包目录的检查只验证兼容版本及能力，不代表它与整份快照逐字节相同。

gptel 0.9.9.6 来自 [NonGNU ELPA 原始 tar](https://elpa.nongnu.org/nongnu/gptel-0.9.9.6.tar)，原 tar
的 SHA256 为 `0aa684b3e273ef6788756cffa4d018fe0bed0ecc853640fb82abaacd9d7ca5dd`；
包标记上游 commit `2b02618b2eba819b996eca7f71bf4dd4b91eb532`。
当前快照中该包的 Lisp 源码（不含生成的描述/加载文件）与原 tar 相符，保留上游的 GNU GPL 许可证和作者信息。
固定版本是为了保留聊天、改写和响应保护所依赖的接口。安装验证在临时 HOME 运行，不读取现有授权，也不发送聊天或改写请求。

## 复建公开离线版

在有网的机器上，从仓库根目录运行以下命令。第一步校验上游归档和补充文件，生成可复用的下载缓存及内层快照。第二步检查快照是否与发行版的固定哈希一致，并生成离线安装器、可解压归档及其校验文件。

```sh
mkdir -p dist
python3 scripts/build-public-bundle.py --cache dist/cache --output dist/public-offline-packages.tar.gz
python3 scripts/make-release.py --public-offline-bundle dist/public-offline-packages.tar.gz --output dist
```

离线版使用独立的番茄钟提示音和窗口边界命令，部分扩展的可选资源有取舍，详见[公开离线版内容](third-party-distribution.md)。安装器使用目标机已有的 Emacs 和 Lisp；SLIME 编译与 REPL 求值可在断网环境中进行，gptel 聊天及改写需要连接模型服务。

## 维护自己的私用快照

`python3 bootstrap/package-bundle.py build --help` 列出构建输入。构建器只选参考清单中的版本；
输入为这些 ELPA 包的源目录、额外 compat 源 tar 和 which-key 源目录。`--reject-prefix` 可供维护者
检查其他机器的个人目录前缀。构建新版本后，审查来源和许可证、做各平台空目录验证，再更新固定的独立 SHA256。
私用源码快照被 gitignore 排除。向第三方公开发布这些依赖及随包资源前，须分别核查再发行条件并保留相应声明。
